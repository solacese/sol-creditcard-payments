# Solace Brand Reference (extracted from Solace Brand Book 2025 v3.0)

Applied to the **POS Sol Terminal** GUI.

## Color palette

### Primary
| Role | Hex | RGB | Notes |
|------|-----|-----|-------|
| Bright / Classic Green | `#00C895` | 0-200-149 | Primary brand color (CMYK 71-0-55-0) |
| Dark Blue | `#093B5F` | 9-59-95 | Pantone 302 |
| Darkest Blue | `#08223C` | 8-34-60 | Deep background |

### Secondary
| Hex | RGB | Notes |
|-----|-----|-------|
| Dark Green | `#009193` | 0-145-147 | Teal secondary |
| `#ABFF88` | pastel green | accent |
| `#C7FFCB` | pale green | accent |
| `#C2F7FF` | pale blue | accent |
| `#FFF7C2` | pale yellow | accent |
| `#FCA829` | orange | accent (used sparingly for warnings) |

### Grays
`#F4F4F4` (Cool gray 13), `#EAEAEA`, `#D6D6D6`, plus white `#FFFFFF`.

### Gradient
**Solace Gradient**: Bright Green `#00C895` → Classic/Dark Green `#009193`.

## Typography
| Level | Font | Usage |
|-------|------|-------|
| Primary | **New Spirit** (serif) | H1/H2 headlines — proprietary (Adobe Fonts). Fallback: `Georgia, serif`. |
| Secondary | **Figtree** (sans-serif) | Body, buttons, labels, UI. Available on Google Fonts. |
| Tertiary | **Space Mono** | Eyebrows, code snippets, compact numerics. Google Fonts. |

The GUI loads **Figtree** and **Space Mono** from Google Fonts; headlines use a
serif stack as a New Spirit stand-in (New Spirit is not freely distributable).

## Usage rules honored in the UI
- Accent/pastel colors are always paired with a primary green (never two secondaries together).
- Body copy never uses secondary colors — text is dark blue / gray on light, white on dark.
- Green `#00C895` is the primary CTA / "approved" signal; `#FCA829`/red used only for declines/warnings.
